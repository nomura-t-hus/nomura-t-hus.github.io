# 身体機能創生研究室 / Human Function Design Lab.

GitHub Pages でそのまま公開できる静的Webサイトです。

## 公開手順

1. GitHubで新しいリポジトリを作成します（例: `human-function-design-lab`）。
2. このフォルダ内のファイルを、リポジトリの最上位（root）へアップロードします。
3. GitHub の **Settings → Pages** を開きます。
4. **Build and deployment** で `Deploy from a branch` を選択します。
5. Branch を `main`、Folder を `/(root)` にして保存します。
6. 数分後、GitHub Pages のURLが表示されます。
