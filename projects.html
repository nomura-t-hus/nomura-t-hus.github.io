Projects

現在取り組んでいる研究・開発領域

公開可能な研究・開発テーマを掲載しています。共同研究や外部機関とのプロジェクトについても、公開可能な範囲で随時更新します。
PROJECT A

義肢の製作・評価を支援する技術

義足の形状設計、アライメント、歩行評価などを対象に、義肢製作における経験知をデータと工学技術で支援する研究を進めています。

PROJECT B

身体動作観察における熟練技能

義肢装具士が歩行・動作を観察する際の視線や判断過程に着目し、熟練者の技能と臨床推論を可視化する研究を行っています。

PROJECT C

スポーツ・身体活動を支えるデバイス

スポーツや身体活動で求められる動作・機能を整理し、身体と用具のインターフェースを設計・評価する研究に取り組みます。

PROJECT D

デジタルモデリングと製作支援

3Dモデリングやソフトウェアを活用し、義肢装具の設計・製作工程を効率化・標準化するための技術開発を行います。

新しい共同研究テーマを歓迎します

医療・福祉・スポーツ・ものづくりの境界領域で、研究シーズの応用や評価方法についてご相談いただけます。
